# Timezone dependency notices

The server uses chrono-tz 0.10.4, chrono 0.4.45, phf/phf_shared 0.12.1 and siphasher 1.0.4 for offline IANA timezone validation. The accompanying files reproduce their MIT license notices (MIT selected for dual-licensed siphasher). These notices ship in the server bundle.

The bundled reminder WAVs are original Field Notes assets, generated by `tools/generate-reminder-tones.py`; no downloaded recordings are used. Existing QR scanner notices remain in the Android APK.

The portable export/import screen bundles fflate 0.8.2 (MIT), from the exact
npm lockfile version, at `apps/admin/vendor/fflate-0.8.2.js`. Its accompanying
license is `fflate-0.8.2-LICENSE.txt`. It runs locally; no CDN or remote archive
service is used. Tasks.org, Vikunja and Super Productivity were reviewed for
workflow ideas; their source code and artwork were not copied.


Reminder audio is original deterministic synthesis from
`tools/generate-reminder-tones.py`, with no sampled recordings. Current Android
and web previews use lossless FLAC encoding; every generated clip is decoded and
compared sample-for-sample by the generator. FFmpeg is a generation tool only
and is not shipped in the app or server. The original v1 WAV preview files remain
unchanged on the server for older open web pages.
