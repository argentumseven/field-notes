# Timezone dependency notices

The server uses chrono-tz 0.10.4, chrono 0.4.45, phf/phf_shared 0.12.1 and siphasher 1.0.4 for offline IANA timezone validation. The accompanying files reproduce their MIT license notices (MIT selected for dual-licensed siphasher). These notices ship in the server bundle.

The bundled reminder WAVs are original Field Notes assets, generated by `tools/generate-reminder-tones.py`; no downloaded recordings are used. Existing QR scanner notices remain in the Android APK.
